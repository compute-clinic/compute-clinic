---
name: review-uml
description: Review the current UML model and report semantic, notation, and cross-diagram issues with corrections.
---

Review all UML-related files in the current project.

Apply the UML core, notation, and review principles. Inspect requirements and existing source before judging the model.

Return:
1. What the model currently represents.
2. Critical errors.
3. Important inconsistencies.
4. Unsupported assumptions.
5. Diagram-specific corrections.
6. Cross-diagram corrections.
7. A corrected PlantUML version when source files are present and correction is unambiguous.

Do not silently change files. First present the findings and proposed corrections.
